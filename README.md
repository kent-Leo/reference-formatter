# 参考文献格式化小工具

粘贴 DOI（支持批量、可混在文字中自动提取），一键生成 **GB/T 7714-2015** 格式的参考文献；也支持手动录入题录。免安装，单文件网页，数据只在本地浏览器处理。

🌐 在线使用：直接用浏览器打开 `index.html` 即可（部署到 GitHub Pages / Cloudflare Pages 同样适用）。

## 功能

- **DOI 批量导入**：逐个查询 Crossref，查不到自动降级 doi.org 再试；失败的 DOI 会明确列出，可一键转手动补录
- **国标格式化**：顺序编码制 [1][2]…；作者超 3 位加「等 / et al」；外文作者姓全大写 + 名首字母；[J]/[M]/[C]/[D]/[EB/OL] 类型映射；缺卷、期、页码自动省略；末尾附 DOI（可关闭）
- **手动录入**：类型、作者、题名、刊名/出版社、年、卷、期、页码、DOI
- **列表管理**：每条可编辑、删除；一键复制全部、导出 .txt、纯文本预览

## 技术

单个 `index.html`（HTML + CSS + JS 全内联），无构建、无后端，题录查询走 Crossref 公共 API。
